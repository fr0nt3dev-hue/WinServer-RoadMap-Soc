# خارطة SOC — مسار الأمن السيبراني

واجهة عربية تفاعلية داكنة بالأزرق، بأرقام إنجليزية (0–9)، لتنظيم 188 درسًا من 3 قوائم يوتيوب وبناء بداية متدرجة لمسار SOC L1.

## التشغيل

افتح `index.html` مباشرة عبر استضافة Static. الصفحة تحتوي على الواجهة والستايل والبيانات ومنطق التفاعل في ملف HTML واحد، ولا تحتاج Build أو Framework.

## المحتوى والوظائف

- 188 عنوانًا من Windows Server 2019 وWindows Server 2022 وMCSA Core.
- تصنيفات: مهم، متوسط، فيما بعد، غير مهم.
- مسار أساسي متسلسل مع دروس بديلة لتجنب التكرار.
- بحث وفلترة حسب الكورس والمدرب والأولوية.
- متابعة التقدم محفوظة محليًا على المتصفح، وتصدير CSV.
- تبويب منفصل لتحديد ما يحتاجه مسار CCNP وما يمكن تأجيله.

## نشر GitHub Pages

1. افتح **Settings → Pages** في هذا المستودع.
2. من **Build and deployment → Source** اختر **GitHub Actions**.
3. احفظ الإعداد. سير العمل في `.github/workflows/deploy.yml` سينشر الموقع تلقائيًا عند كل Push إلى `main`.
4. راجع تبويب **Actions** لمعرفة حالة النشر ورابط الموقع.

## نشر Vercel

- Framework Preset: **Other**.
- Build Command وInstall Command: فارغان.
- Output Directory: `.`.
- Root Directory: جذر المشروع.

## مصادر البيانات وحدود المراجعة

- 93 عنوانًا من Windows Server 2019، و64 من Windows Server 2022، و31 من MCSA Core.
- التصنيف مبني على العناوين الظاهرة في الملف النصي المرفق وسياق فائدة الموضوع لمبتدئ SOC L1.
- لا يتضمن الملف تفريغات الفيديوهات، لذا لا ندّعي مشاهدة التسجيلات كاملة أو تحليل محتوى غير ظاهر في العنوان.
- معرّفات الفيديوهات الفردية لم تكن مدرجة؛ روابط الدروس في الواجهة تفتح قائمة يوتيوب أو بحثًا بعنوان الدرس.
