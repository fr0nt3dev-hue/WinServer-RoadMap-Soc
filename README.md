# خارطة SOC — مسار الأمن السيبراني

موقع عربي تفاعلي بتصميم داكن أزرق لترتيب 188 عنوان درس من ثلاث قوائم YouTube، مع تصنيف الأولوية، مسار متسلسل لبداية SOC L1، فلترة وبحث، تتبع إنجاز محلي، وتصدير CSV.

## الملفات
- `index.html`: واجهة الموقع.
- `styles.css`: التصميم الأزرق الداكن.
- `app.js`: التفاعلات والفلترة وتتبع التقدم.
- `data.js.gz.b64`: بيانات الدروس مضغوطة كنص، ويفكها المتصفح عند التحميل.
- `.github/workflows/deploy.yml`: نشر GitHub Pages.
- `vercel.json`: إعداد Vercel.

## تشغيل محلي
شغّل `python -m http.server 8000` من جذر المشروع ثم افتح `http://localhost:8000`.

## تحديث البيانات
الملف المصدر غير المضغوط `data.js` متوفر في حزمة ZIP. بعد تعديله أعد إنشاء `data.js.gz.b64` باستخدام gzip وBase64 ثم ارفع التغيير. لا توجد خطوة Build.

## النشر
المشروع Static HTML/CSS/JS. على Vercel استخدم Framework Preset = Other، وبدون Build Command، وOutput Directory = `.`.

## نطاق المراجعة
تم إدخال 93 عنوانًا من Windows Server 2019، و64 من Windows Server 2022، و31 من MCSA Core. التصنيف مبني على العناوين الظاهرة في الملف المرسل وسياق فائدتها لبداية SOC، وليس على ادعاء مشاهدة جميع التسجيلات.
